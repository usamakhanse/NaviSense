# 📍 NaviSense – Smart Indoor Navigation System

NaviSense is a Smart Indoor Navigation System designed to help users navigate shopping malls through a simple and user-friendly interface.

## UI Functionalities

1. **Home Screen** – Displays the main navigation interface.
2. **QR Scanner Screen** – Provides an interface for QR code scanning.
3. **Destination Search** – Allows users to search for shops and locations.
4. **Facility Finder** – Displays options for washrooms, prayer rooms, and emergency exits.
5. **Navigation Screen** – Displays the indoor navigation interface.
6. **User Profile & Settings** – Provides user settings and app preferences.

## Technologies Used
- XML
- Android Studio

## Setup Instructions
1. Clone or download the repository.
2. Open the project in Android Studio.
3. Open the XML layout files.
4. Run the project using an Android emulator.
